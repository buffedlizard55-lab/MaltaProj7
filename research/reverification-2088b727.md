# Line-by-line source re-verification — session arena/2088b727-maltaproj7 (2026-10-18)

Independent re-verification of every catalog record in `data/events.json` (105 rows + 3 rows added by concurrent session PR #17 = 108 rows; 16 field flags) against the official source URL attached to each row. Method: each unique `source_url` fetched directly via the sandbox fetch tool on 2026-10-18 (outbound curl is blocked by sandbox network policy); the returned official-page text was compared against the row's name, cadence/date, San Francisco location, and any filled optional fields (time, admission, location detail). A row is marked **PASS** only when the linked official page supports its core claims; unsupported values would be blanked and flagged (none may be inferred). Verdict marks:

- **PASS** — live official page supports the row's core claims (name, date/cadence, SF location) and every filled optional field on the row is stated by the source.
- **PASS\*** — core claims confirmed; some optional detail confirmed only partially or via text elsewhere on the fetched page — noted inline.
- **FAIL→FIX** — source contradicted the row; correction applied to `data/events.json` and noted inline (change log at end).
- **FLAG** — discrepancy retained and published on Flagged for Review; row remains with documented disposition.

Rows sharing one source URL are verified together (one fetch covers each row listed). Flags are cross-checked against their cited `sources` URLs as well.
